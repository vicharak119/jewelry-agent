Administrator Guide

Jewelry Marketing Agent — Setup

Everything you need to get your studio running, from first login to daily settings. Version v8.8

What this tool does

You upload a plain photo of a jewelry piece; the app studies it, places it into a styled marketing scene while keeping the exact piece intact, and overlays your brand (logo, name, tagline) and an optional product code. Everything runs on your own Cloudflare account, with your own OpenAI key.

1. First-time setup

Step 1

When an instance has no admin yet, the first screen is First-Time Setup. Enter:

  • Admin username — your login name (lowercase, no spaces is safest).
  • Email — optional, used for greetings and future email features.
  • Admin password — minimum 8 characters, with at least one uppercase letter, one number, and one special character.

Click Create Admin Account. You're now signed in as administrator.

2. Get your OpenAI API key

Step 2
  1. Go to platform.openai.com and sign in.
  2. Open API keys → Create new secret key, copy it (starts with sk-).
  3. Make sure your OpenAI account has billing/credits enabled, or image generation will fail.
  4. Paste the key into Settings → OpenAI API Key (next section) and Save.
Cost: each image is roughly Rs 0.5 (draft), Rs 4–5 (standard), or Rs 15–18 (premium). These are estimates — your real charges appear on your OpenAI billing page.

3. Settings — every field

Open the Settings tab (admin only). Fill in and Save Settings.

OpenAI API KeyYour sk-… key. Once saved it shows as "configured"; leave blank to keep the existing one.
Brand NamePrinted on every image (e.g. your shop name).
TaglineSmall line under the brand name. Optional.
Image ModelDefault gpt-image-2. This is the model that edits your photo into a scene. Only change it if OpenAI renames it.
Image SizeDefault 1024x1024. Square works best for catalog/social.
Default QualityDraft / Standard / Premium. Higher = better and slower (and costlier).
Default Logo PositionWhere the logo + brand text sit (corners, bottom-centre, or none).
Logo size (% of width)How large the logo is, as a percentage of the image width. Default 12.
Brand name size (% of height)Brand-name text size. Default 5.
Tagline size (% of height)Tagline text size. Default 3.
Default code positionDefault corner for the product code.
Code size (% of height)Product-code text size. Default 3.
Auto-delete images after (days)Old images and their history rows are removed automatically after this many days. 0 = keep forever. Default 30. The audit log and your logo are always kept.
Tip: the three size fields are independent — set each to taste. After changing them, open a generated image and press Re-apply branding to see the new sizes instantly (no new AI cost). There's also a Clean up now button to run retention deletion on demand.

4. Brand logo

Step 3

In Settings, under Brand Logo, choose an image and click Upload Logo. A PNG with a transparent background works best. The tool now detects your logo's real shape (square, round, or rectangular), trims empty padding, and keeps its proportions — no more squashing into a circle. The brand name/tagline sit beside a square/round logo and below a wide rectangular one automatically.

5. Users

Step 4

The Users tab (admin only) manages who can sign in.

  • Add User: enter a username, optional email, a temporary password, and a role (User = create images only; Admin = full access). They'll be forced to set their own password at first login.
  • Reset PW: generates a one-time temporary password shown in a banner — copy it and share it; the user must change it at next login.
  • Delete: removes a user (you can't delete yourself).

6. Backup & export

Step 5

The Backup tab offers:

  • Download Logs (CSV) and Download Images (ZIP) — instant local backups, no Google account needed.
  • Google Drive Backup (optional): in Google Cloud Console create a project, enable the Drive API, create OAuth (Web App) credentials, and add the redirect URI shown on that screen (it ends in /api/drive/callback). Paste the Client ID + Secret, Save, then Connect Drive and authorise. Use Backup Now any time.

7. Audit log

The Audit tab (admin only) records security and admin events — logins (including failures), password changes/resets, user create/delete, settings changes, logo uploads, downloads, exports, backups, cleanups, and blocked admin attempts — each with who, when (IST), and the client IP. Use the column filters and click headers to sort. The audit log is never auto-deleted.

8. Security & recovery

Your login secret lives in Cloudflare, not in the code. Each instance sets a JWT_SECRET as an encrypted Secret in its Cloudflare Pages dashboard (Settings → Variables and Secrets). Never put it in a file in the repo.
  • Keep a second admin so you're never locked out.
  • If the only admin is locked out, an account owner can reset the password directly in the database (D1 console) — see your release notes for the exact statement.
  • If you ever suspect the secret leaked, rotate it in the dashboard (everyone simply logs in again once).

9. Troubleshooting

I deployed but don't see changesOpen the site in a private/incognito window to confirm, then clear the cache once (reinstall the PWA or clear site data). After that, updates appear on reload automatically.
Logo looks small or blurryRaise the Logo size % in Settings and press Re-apply branding. Use a high-resolution square PNG.
Branding size didn't changeBranding is baked in when an image is generated. Change the size, Save, then Re-apply branding (or generate a new image).
Generation failed / no imageCheck the OpenAI key is valid and the account has credits. The error message on screen states the reason.
The piece looks alteredThe app edits your real photo to preserve it, but it's still AI — re-generate, or refine the editable prompt before generating.
